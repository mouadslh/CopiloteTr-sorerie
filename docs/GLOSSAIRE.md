# Glossaire

| Terme | Définition de travail |
|---|---|
| Échéance légale | Date limite estimée selon les paramètres de cadrage applicables. |
| Mois de retard | Nombre de périodes de 30 jours entamées après l'échéance, selon l'hypothèse du prompt. |
| ICE | Identifiant commun de l'entreprise. |
| UBL | Universal Business Language, format XML structuré de documents commerciaux. |
| Taux directeur | Paramètre monétaire utilisé dans la formule d'amende du cadrage. |
| Quantile | Valeur sous laquelle se trouve une proportion donnée d'observations. |
