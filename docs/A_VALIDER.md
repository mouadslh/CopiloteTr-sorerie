# Points à valider

Les hypothèses ci-dessous sont celles du prompt master pour construire le MVP ; statut : **non validé**. Elles ne constituent pas une interprétation juridique.

| Point | Hypothèse de cadrage | Statut |
|---|---|---|
| Départ du délai | Point de départ à confirmer (livraison, réception ou facture) ; le moteur utilise la date de facture fournie | Non validé |
| Mois de retard | Mois entamé = ceil(jours / 30) | Non validé |
| Bénéficiaire de l'amende | Le prompt évoque le Trésor | Non validé |
| Secteurs à 180 jours | Plafond sectoriel à 180 jours, secteurs concernés à préciser | Non validé |
| Taux directeur | 2,25 % utilisé comme exemple versionné en YAML | Non validé |
| Facturation électronique | Spécifications UBL de la DGI à vérifier | Non validé |
| Données personnelles | Obligations CNDP / loi 09-08 selon l'hébergement | Non validé |
| Courriers | Mentions à faire valider par juriste ou expert-comptable | Non validé |
